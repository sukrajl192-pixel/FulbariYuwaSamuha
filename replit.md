# Fulbari Yuwa Samuha — Saving & Loan Management System

A bilingual (Nepali/English) cooperative savings and loan management web app built with React + Vite and Firebase Realtime Database.

## How to run

The **Start application** workflow runs `npm run dev` and serves the app on port 5000.

## Stack

- **Frontend:** React 19, Vite 8
- **Backend/DB:** Firebase Realtime Database (`fys-a0411` project, Asia Southeast region)
- **Auth:** Custom role-based login (Admin / Member)

## Firebase

Firebase credentials are hardcoded in `src/firebase.js` (standard practice for Firebase web SDKs — these are public client identifiers, not secret keys). No additional secrets are needed to run.
